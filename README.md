# 🛡️ Enterprise SOC Home Lab

## Overview

This repository documents my hands-on Enterprise Security Operations Center (SOC) Home Lab. The project is designed to simulate a real-world enterprise environment where I can build, configure, monitor, detect, and investigate security events using industry-standard tools and technologies.

The purpose of this lab is to strengthen my practical cybersecurity skills while building a professional portfolio that demonstrates real-world experience.

---

# Objectives

- Build an enterprise Active Directory environment
- Deploy Windows Server and Windows 11 endpoints
- Configure centralized logging
- Deploy Sysmon for endpoint telemetry
- Integrate Elastic Security for log analysis and detection
- Simulate real-world cyber attacks
- Perform threat hunting and incident response
- Document findings and lessons learned
